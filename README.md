

# (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧ PR Portfolio Generator

> Automatically generate a beautiful GitHub portfolio from your merged Pull Requests.

Transform your GitHub contributions into a clean, shareable README. This action fetches all your merged Pull Requests and automatically generates a portfolio that showcases your open-source contributions.

Perfect for:

*  GitHub Profiles
*  Developer Portfolios
*  Resume Projects
* Hackathons
* Open Source Contributors

---

# 👈(ﾟヮﾟ👈) Features

*  Fetches merged Pull Requests automatically
*  Generates a portfolio-ready README
* Fully automated using GitHub Actions
*  Supports scheduled updates

---

# 📂 Generated Files

After running the action, the following files will be created or updated:

```
README.md
output/
└── prs.json
```

* **README.md** → Portfolio generated from merged PRs
* **output/prs.json** → Raw Pull Request data

---

#  Installation

Create the following workflow in your repository:

```
.github/workflows/pr-portfolio.yml
```

Paste the following:

```yaml
name: Update PR Portfolio

on:
  workflow_dispatch:

  schedule:
    - cron: "0 */12 * * *"

permissions:
  contents: write

jobs:
  update:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Generate PR Portfolio
        uses: stargalax/pr-portfolio-action@master

        with:
          username: YOUR_GITHUB_USERNAME

      - name: Commit changes
        run: |
          git config user.name github-actions
          git config user.email github-actions@github.com

          git add README.md output/prs.json

          git diff --cached --quiet || git commit -m "Update PR portfolio"

          git push
```

---

#  Configuration

Replace:

```yaml
username: YOUR_GITHUB_USERNAME
```

with your GitHub username.

Example

```yaml
username: octocat
```

---

# Running the Action

## Manual

Go to

```
Repository
→ Actions
→ Update PR Portfolio
→ Run workflow
```

---

## Automatic

The workflow is scheduled to run every **12 hours** using

```yaml
schedule:
  - cron: "0 */12 * * *"
```

You can modify the cron expression if you'd like a different schedule.

#  Prerequisites

Before using this action, make sure you have at least **one merged Pull Request**.

If you don't have one yet:

1. Create a new branch.

```
git checkout -b feature-demo
```

2. Make a small change.

3. Commit and push.

```
git add .
git commit -m "Demo change"
git push origin feature-demo
```

4. Open a Pull Request.

5. Merge it.

Now you're ready to generate your portfolio.

# (〃￣︶￣)人(￣︶￣〃) Troubleshooting

### Invalid workflow file

```
Unexpected value 'username'
Required property is missing: jobs
```

**Cause**

Only the username was added instead of the complete workflow.

**Solution**

Copy the entire workflow into

```
.github/workflows/pr-portfolio.yml
```

---

### Unable to resolve action

```
Unable to resolve action
stargalax/pr-portfolio-action@main
```

**Cause**

The repository uses the **master** branch.

**Solution**

Replace

```yaml
uses: stargalax/pr-portfolio-action@main
```

with

```yaml
uses: stargalax/pr-portfolio-action@master
```

---

### No Pull Requests Found

Ensure that:

* Your username is correct.
* You have at least one merged Pull Request.
* The workflow has permission to read your repositories.
