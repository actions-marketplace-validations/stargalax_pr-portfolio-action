# PR Portfolio Generator

Automatically generates a README from your merged GitHub Pull Requests.

## Setup

1. Create a file:   .github/workflows/pr-portfolio.yml


2. Add the template from examples\basic.yml into pr-portfolio.yml file

3. Replace YOUR_GITHUB_USERNAME in the above file with your username

4. Go to Actions--> the repo --> Run workflow

5. Check your repository:  Readme.md, output/prs.json will be created
